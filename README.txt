# The Nature Food Ahaa! — Static Website

## Files
- `index.html` — website structure
- `style.css` — responsive design + animations
- `script.js` — product filtering, YouTube gallery and interactions
- `assets/logo.png` — supplied Ahaa logo

## Run locally
Open `index.html` directly in a browser, or use VS Code Live Server.

## Add YouTube videos
Open `script.js` and edit:

```js
const videos = [
  {id:"YOUR_VIDEO_ID", title:"Ahaa! Product Story", note:"Our latest video"},
  {id:"YOUR_VIDEO_ID", title:"From Farm to Food", note:"Behind the scenes"},
  {id:"YOUR_VIDEO_ID", title:"The Nature Food Ahaa!", note:"Product showcase"}
];
```

For:
`https://www.youtube.com/watch?v=ABC123XYZ`

the video ID is:
`ABC123XYZ`

## Easy deployment
This is a plain HTML/CSS/JS website, so it can be uploaded directly to:
- GitHub Pages
- Netlify
- Vercel
- Any normal web hosting
